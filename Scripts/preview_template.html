How this preview is built

One HTML file with no chart libraries. Scripts/build_preview.py reads Data/beverages_data.csv and embeds it as JSON, so the preview always matches the data in the repository.

The full Power BI report is in Dashboard.pbix, and screenshots of each page are in the Previews folder.

Notes

This is an independent portfolio project and is not affiliated with or endorsed by Starbucks.

The 400 mg caffeine marker is the commonly cited daily guideline for healthy adults, and calories are compared with a 2,000 kcal reference day.
